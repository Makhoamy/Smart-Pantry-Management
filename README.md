Smart Pantry Manager
About the app
Smart Pantry Manager is an Android app that helps users keep track of food in their kitchen. Users can add pantry items, view recipes and get suggestions based on the food they have. Recipes that use food expiring soon appear first to help reduce food waste.
Main features
- Add, edit and delete pantry items.
- View recipes, ingredients and instructions.
- Get suggestions only when all the required ingredients are available in enough quantity.
- Show recipes that use ingredients with the closest expiry dates first. Expired items are ignored.
- Choose Metric or Imperial units in Settings.
- Save settings by pressing Apply settings.
- Add sample pantry items and recipes when the app is opened for the first time.
